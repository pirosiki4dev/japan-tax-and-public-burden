- 抽出した候補: 393件（法律、廃止・失効を除く）

## 目的と方法

日本の税と公的負担を網羅した公的な一覧はないため、e-Gov法令APIの法令データを母集団とし、記録した条件で候補の法律を抽出して、全件を判定した。網羅の範囲は「下記の抽出条件で得た法律を、すべて判定済み」であり、網羅性を証明するものではない。照合にはe-Gov法令検索（e-Gov法令API）だけを使い、他の一覧は使っていない。

このフォルダは通常運用（検証、配布物の生成、監視）では使わない。通常運用の成果物と混ざらないよう、調査用のプログラム・Schema・テストもこのフォルダに置く。

| ファイル | 内容 |
| --- | --- |
| `conditions.yaml` | 抽出条件 |
| `candidates.json` | 抽出結果（プログラムが出力。手で編集しない） |
| `judgments.yaml` | 全件の判定と理由・根拠条項 |
| `schemas/` | 上記3ファイルのJSON Schema |
| `src/` | 抽出プログラム（e-Gov法令APIのクライアント、抽出、差分、判定の検査）と、Schemaから生成した型（`types.generated.ts`。`node surveys/first-release-scope/src/generate-types.ts` で再生成） |
| `tests/` | テスト（`npm test` に含まれる） |

## 再検証の方法

```sh
node surveys/first-release-scope/src/cli.ts --check   # 再実行し、記録済みの抽出結果との差分を表示する（差分があれば終了コード1）
node surveys/first-release-scope/src/cli.ts           # 抽出結果を書き直す（その後、judgments.yaml の判定を更新する）
npm test                                              # 全件に判定があること、対象と data/legal-sources.yaml が一致することを検査する
```

## 根拠不足・未確認の事項

- **防衛特別所得税**: 全文検索「防衛特別所得税」でe-Gov法令APIに該当する法律がなかった。現行の法令データに規定がないため登録していない。
- **全文検索の対象**: 全文検索が施行前の改正内容（公布済み未施行）を対象とするかは確認できていない。公布済み未施行の改正は、#144〜#146 で各法律の改正履歴（改正版の一覧）から確認する。
- **未確認の記述**: 「全体の範囲だが初回は対象外」のうち、再評価税・地価税（課税停止の条項）・法人特別税・湾岸臨時税の現在の扱いは条文を精読していない。過去の制度を扱う段階、または旧版との突合（#155）で確認する。

## 抽出条件の限界

- **法令分類のばらつき**: e-Govの法令分類は法令の性格と一致しない場合がある（例: 地方税法は「地方財政」、介護保険法・子ども・子育て支援法は「社会福祉」、労働保険の保険料の徴収等に関する法律は「労働」、特別法人事業税及び特別法人事業譲与税に関する法律は「地方財政」）。分類と全文検索を組み合わせて補った。
- **全文検索の語句への依存**: 規定の言い回しが検索語句と異なる負担は漏れる可能性がある。「税を課する」「保険料率」は、非課税規定や他の法律への言及にも該当するため、候補が多くなる。
- **抜粋は条件ごとに先頭の1文**: `candidates.json` の `snippets` は判定の補助で、該当箇所のすべてではない。
- **法令分類だけで抽出された候補の判定**: 全文検索の条件に該当しない「社会福祉」「労働」の法律は、題名・目的から負担を課す規定がないと判断した。条文全体は精読していない。
- **法律だけが対象**: 政令・省令・告示は抽出していない。委任先の政令・省令は、#144〜#146 で各負担項目の `provisions` として特定する。

## 後続の作業への申し送り

- **関税**: 関税定率法の関税率表と関税暫定措置法の暫定税率は品目ごとに数千の税率がある。#144 で負担項目の単位を決める必要がある。
- **社会保険料**: 健康保険料・国民健康保険料・後期高齢者医療保険料・介護保険料の率・額は保険者が定める。#146 では法令で定まる値（保険料率の範囲、賦課限度額、所得段階の基準等）だけを登録する。
- **reviewed_revision_id**: `data/legal-sources.yaml` の値は抽出時点の現行の改正版である。#144〜#146 はこの版を基準に負担項目を登録する。
