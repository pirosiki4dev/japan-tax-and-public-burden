# 最初のリリースの対象と旧版マスタの突合（legacy-master-comparison）

- 対応Issue: #155
- 比較した旧版: `legacy-v0` タグの `data/master/canonical.json`（正本112件）と `data/master/initial-import.json`（正本に入らなかった保留7件）。計119件
- 比較した新しい調査: `surveys/first-release-scope/`（#143）と `data/groups.yaml`

旧版は比較のためだけに使い、旧版のデータや調査結果を根拠にしていない。このフォルダは通常運用では使わない。

## 結論

- **国税・地方税・社会保険料（最初のリリースの範囲）に抜けはなかった。** 旧版のこの範囲の52件は、すべて最初のリリースの対象のグループに対応した。旧版で保留だった防衛特別法人税も、新しい調査では根拠条項を特定済み。
- **旧版との差の大半は、区分 ot（法令に基づく賦課金・拠出金・負担金）だった。** 56件は ADR 0002 により全体の範囲だが、最初のリリースの対象外として意図的に外したもの。これらの根拠法令36法律のうち23法律は、#143 の抽出条件（国税・地方税・社会保険料向け）では候補に入っていない。
- **#143 の判定を4件修正した。** 旧版で区分 ot の負担の根拠とされていた法律のうち4件を、#143 では「対象外」と判定していた。「初回は対象外（later）」に直した（下記）。
- **ユーザーの判断が必要なものが7件ある。** 補償金・託送料金を通じた負担金など、対価か負担かの線引きが必要なもの。

## 再検証の方法

```sh
node surveys/legacy-master-comparison/src/extract.ts   # legacy-v0 タグから legacy-items.json を作り直す
npm test                                             # 全件の対応付けと、#143 の判定との整合を検査する
```

| ファイル | 内容 |
| --- | --- |
| `legacy-items.json` | 旧版マスタから取り出した比較対象（プログラムが出力。手で編集しない） |
| `mapping.yaml` | 旧版の各項目と新しい調査の対応、理由 |
| `src/` | 取り出し（`extract.ts`）、対応付けの検査（`compare.ts`） |
| `tests/` | テスト（`npm test` に含まれる。`legacy-v0` タグがない環境では、タグとの一致の検査を省略する） |

1. **区分 ot を扱う段階で、負担金等の語句の条件を追加する。** 例: 全文検索「負担金を徴収」「拠出金を徴収」「賦課金を徴収」「負担金を納付」「拠出金を納付」「納付金を納付」。今回の ot の根拠法令36法律のうち23法律は、国税・地方税・社会保険料向けの条件では候補に入らなかった。
2. **抜粋だけで「対象外」と判定しない。** 全文検索の抜粋は条件ごとに先頭の1文だけのため、非課税規定の抜粋だけで対象外とすると、同じ法律の別の条にある負担を見落とす（今回の4件）。対象外と判定する前に、負担金・拠出金・賦課金・納付金の語句で同じ法律を追加検索する。
3. **政令・省令を候補に含める。** 旧版の電気事業法施行規則のように、負担の根拠が省令にあるものは、法律だけの抽出では拾えない。
