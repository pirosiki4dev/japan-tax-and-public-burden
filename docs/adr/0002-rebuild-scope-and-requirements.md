## 文脈

旧構成は段階的な機能追加により責務の混在、制度別分岐のコード直書き、文書の陳腐化を抱えたため、フォルダ構成から設計し直して作り直す（#139）。設計に先立ち、最初のリリースに関わらずプロジェクト全体で何を対象とするかを確定し、その後に最初のリリース範囲を決める。

本ADRは要件と対象範囲だけを定める。データ形式、実装言語、フォルダ構成、データモデル、監視方式はADR 0003で決める。

## 決定

### 目的

日本の税と公的負担を、公式一次情報の根拠付きで構造化し、制度の新設・改廃・率や金額の変更・適用開始・終了を継続的に追跡する。リポジトリ名のとおり、税と公的負担を網羅することを全体の目標とする。

個別の税額計算サービス、税務・法務上の助言、将来の成立や適用の断定は目的としない。

### 全体の対象範囲

#### 1. 対象とする負担の判定基準

法令に基づき、次のいずれかに当たる金銭負担を対象とする。

- 反対給付なしに徴収されるもの
- 加入または支払いが法令で義務付けられているもの

| 区分 | 扱い |
| --- | --- |
| 国税 | 対象 |
| 地方税（道府県税・市町村税の法定税） | 対象 |
| 地方税（道府県税・市町村税の法定外税） | 対象 |
| 社会保険料（年金、医療、介護、雇用、労災、子ども・子育て支援金等） | 対象 |
| 法令に基づく賦課金・拠出金・負担金 | 判定基準に当てはまるものを対象 |
| 行政手数料、使用料、公共料金 | 対象外（個別のサービスへの対価のため） |
| 罰金、科料、過料 | 対象外（制裁であり負担ではないため） |
| その他（上記の区分だけでは判定できないもの） | 個別に判断する |

#### 個別判断の記録

- 対象と判断した負担は、判断、理由、根拠URLを `data/scope-decisions.yaml` に記録する。この文書には一覧を持たない。
- 対象外と判断した負担は、データには記録せず、次の表に判断と理由を記録する。
- 負担のきっかけとなる行為（自動車の保有、受信設備の設置、電話の契約等）を本人が選べることは、対象外とする理由にしない。税にも同じ構造のもの（消費税、たばこ税、自動車税等）があるため。

| 負担 | 判断日 | 対象外とする理由 |
| --- | --- | --- |
| 特別土地保有税（地方税法第五百八十五条以下） | 2026-11-05 | 地方税法附則第三十一条により、土地と遊休土地に対するものは平成十五年度以後の年度分、土地の取得に対するものは平成十五年一月一日以後の取得について、「当分の間」課さないとされ、現に課されていない。本則の税率を登録すると、課されない負担が集計に入るため対象外とする。附則第三十一条の改正で課税が再開されるときは、改めて判断する（#145） |
| 附帯税（国税通則法第二条第四号、第六章。延滞税、利子税、過少申告加算税、無申告加算税、不納付加算税、重加算税） | 2026-11-10 | 国税通則法上は国税だが、本税（所得税・消費税等）の法定納期限までの納付・期限内の申告をした者には生じない。延滞税・利子税は納付の遅延・延納の期間に応じた利息の性格、加算税は申告・納付の義務違反に対する行政上の制裁の性格をもつ。判定基準の「反対給付なしに徴収されるもの」に形式上は当たるが、罰金・科料・過料を制裁として対象外とした扱いに準じて対象外とする。#143 の法令調査で判断保留とし、ユーザーの判断で対象外とした（#181） |

#### 2. 課す主体の単位

国、都道府県、市区町村、保険者（協会けんぽ、健康保険組合、共済組合、国民健康保険、後期高齢者医療広域連合、介護保険者等）のすべての単位を対象とする。自治体別・保険者別の個別の率・金額まで網羅する。

#### 3. 対象期間

| 期間 | 全体の範囲 |
| --- | --- |
| 現行の有効な制度 | 対象 |
| 公布済みで施行前の制度 | 対象 |
| 廃止された過去の制度 | 対象（最終的に含める） |
| 法案段階の制度 | 対象外（データとしては保持しない。法案段階の監視方法は別途検討する） |

#### 4. 情報の詳しさ

次のレベル5まですべてを全体の範囲とする。

| レベル | 内容 |
| --- | --- |
| 1 | 制度の存在、分類、根拠法令 |
| 2 | 納税義務者・負担者、課税対象、課税標準・算定基礎 |
| 3 | 税率・料率・金額、段階的な適用 |
| 4 | 減免、特例、経過措置 |
| 5 | 税収・徴収実績、国民負担率との対応 |

#### 5. 継続監視

対象の制度について、法令改正や料率改定を継続的に検知する。自動検知と人の確認の範囲の分け方は設計ADRで決める。

### 最初のリリースの範囲

| 観点 | 最初のリリース | 全体の範囲 |
| --- | --- | --- |
| 制度の種類 | 国税（関税を除く）、地方税（法定税）、社会保険料 | 判定基準に当てはまる負担すべて（賦課金・拠出金・負担金を含む） |
| 課す主体の単位 | 国、地方自治体（地方税法等の法令上の制度と標準税率まで） | 国、地方自治体（各自治体の条例上の税率を含む）、保険者 |
| 対象期間 | 現行の有効な法律、公布済みで未施行の法律 | 過去の制度を含む |
| 情報の詳しさ | レベル3（税率・料率・金額、段階的な適用）まで | レベル5まで |
| 継続監視 | 下記のe-Gov法令API監視 | e-Gov法令APIに加え、自治体・保険者等の公式サイトを順次対象に加える |

自治体・保険者等の公式サイトは、地方自治体や保険者が個別に率・金額を決定する負担をデータの対象に加えるときに、あわせて監視対象へ加える。

#### 最初のリリースの継続監視

1. 最初のリリースの対象制度の根拠法令について、GitHub Actionsでe-Gov法令APIを定期的に監視する。
2. 法令の改正を検知したら、根拠URLと検知日時を付けたIssueを自動で作成する。
3. 人間がIssueを確認し、マスタへ反映するかを判断する。反映する場合は、公式根拠に基づくPull Requestで行う。

監視からマスタを自動で更新するPull Requestは作成しない。

#### 最初のリリースの範囲の詳細

- 地方税は、地方税法等の法令で定める法定税の制度と標準税率・制限税率までを対象とする。法定外税、各自治体の条例上の税率、自治体独自の減免は対象外とする。
- 社会保険料は、法令で定まる率・金額だけを対象とする。協会けんぽの都道府県別料率、健康保険組合・国民健康保険・後期高齢者医療・介護保険者ごとの料率や金額等、保険者が決定する値は対象外とする。法令の率を厚生労働大臣が告示で全国一律に変更する率（雇用保険率）は、告示の値を対象とする（#146）。
- 地方税の特例による軽減・重課はレベル4に当たり、最初のリリースでは登録しない（#165）。本則の標準税率・制限税率だけを登録する。国税の租税特別措置法による軽減（#160）も同じ扱いとする。全体の範囲へ広げるときに、ADR 0003 のとおり `data/reliefs.yaml` に登録する。登録しない特例は次のとおり（地方税法の条項）。
  - 自動車税・軽自動車税のグリーン化特例による軽減・重課（附則第十二条の三、第十二条の四第三項、第三十条）。期間を限り、本則の税率を読み替える。
  - 積雪地域に主たる定置場を有する自動車の自動車税の標準税率（第百五十四条第三項）。本則の条項だが、政令で定める割合で第百五十四条第一項・第二項の標準税率を軽減するものであるため、軽減として扱う。
  - 法人事業税の大規模な協同組合等の所得割の特例（附則第九条の二）。租税特別措置法第六十八条第一項に該当する法人の所得割の税率の区分を読み替える。
  - 狩猟税の特例（附則第三十二条の二）。令和十一年三月三十一日までに受ける狩猟者の登録で、申請前一年以内に鳥獣保護管理法第九条第一項の許可による捕獲等を行った者などの狩猟税の税率を、本則の税率に二分の一を乗じた税率とする。
  - 国民健康保険税の減額（第七百三条の五）。政令で定める基準に従い、市町村の条例で減額する。
  - 個人の市町村民税の均等割の軽減（第三百十一条）。市町村の条例で軽減する。
- 法定税のうち、地方税法に税率・税額の定めがなく、税率を条例で定める水利地益税（道府県税・市町村税。第七百三条）、共同施設税（第七百三条の二）、宅地開発税（第七百三条の三）は対象外とする（#164）。理由は次のとおり。
  - 地方税法には、課税額が「特に受ける利益の限度」を超えられないという上限（水利地益税、共同施設税）か、税率を条例で定めるという規定（宅地開発税）しかなく、ADR 0003の「1つの率または金額ごとに1つの負担項目」で登録できる値がない。
  - 総務省の税目の説明（例: 水利地益税 https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/173414_3.html ）も、税率を「条例の定めるところによる」としている。税率を全国一律に公表する国の資料はなく、値は課税する団体の条例にしかない。雇用保険率（#146）のように、国の公表ページの値を登録して監視する方法はとれない。
  - 税目は `data/groups.yaml` の集計用グループとして残す（所属する負担項目はない）。地方税法の条文の改正は、e-Gov法令APIの監視で検知する。各自治体の条例上の税率を対象に加えるとき（全体の範囲）に、改めて登録する。
- 地方自治法第二百二十四条の分担金は、全体の範囲では対象とし（`data/scope-decisions.yaml`）、最初のリリースでは対象外とする（#183）。理由は次のとおり。
  - 分担金は地方税ではなく、法令に基づく賦課金・負担金の区分に当たり、最初のリリースの制度の種類（国税、地方税（法定税）、社会保険料）に含まれない。
  - 分担金に関する事項は地方自治法第二百二十八条により条例で定め、法令には率・金額の定めがない。値は、下水道事業・土地改良事業等の事業ごとに各地方公共団体の条例にしかなく、各自治体の条例上の値を対象に加えるとき（全体の範囲）に、あわせて登録する。
- 関税は対象外とする（#161）。理由は次のとおり。
  - 関税定率法の関税率表（基本税率）は税率の欄が約7,670件あり、関税暫定措置法の暫定税率・特恵税率も数百件ある。ADR 0003の「1つの率または金額ごとに1つの負担項目」で登録すると、正本と配布物がそれぞれ数十MB（正本は約50MB）になり、Pull Requestでのレビューと配布が難しい。
  - 輸入の多くに実際に適用される税率は、条約で定まるWTO協定税率とEPA税率で、e-Gov法令APIでは取得できない。法律の表だけを登録しても、実際の負担を表さない。
  - 関税を対象に加えるときは、負担項目の単位（品目ごとか、表ごとか）と、条約で定まる税率の根拠・監視の方法を、改めて決める。
- 自動監視の対象はe-Gov法令APIで取得できる法令と、対象とした告示の値を公表する国の公式ページ（`config/sources.yaml` に置く。現時点では厚生労働省の雇用保険料率のページ）とする。条例、保険者の決定等、それ以外の根拠は自動監視の対象外とし、自治体・保険者等の公式サイトは後続で対象に加える。

### データ記録の原則

`AGENTS.md` の基本方針（公式一次情報の優先、`source_url` と確認日時、公布日・施行日・適用開始日・徴収開始日の個別管理、原文と正規化値の併記、`unknown` と根拠不足の記録、金額の確定区分・期間・単位・集計範囲、内数の二重計上防止）を前提とする。`AGENTS.md` 自体の見直しは #139 の後続工程で行う。

## 結果

全体の範囲が自治体別・保険者別の値、過去の制度、レベル5まで及ぶため、データ量と収集工数は大きい。データモデルとフォルダ構成は、最初のリリースが小さい範囲でも、この全体の範囲へ作り直しなしで拡張できることを設計条件とする。
